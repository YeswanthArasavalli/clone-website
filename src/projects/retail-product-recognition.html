🛒 Retail Product Image Recognition System

Deep Learning-Based Computer Vision using PyTorch & EfficientNet-B0

PyTorch EfficientNet-B0 Streamlit Deep Learning Computer Vision

📋 Project Overview

An end-to-end deep learning system that classifies retail product images into SKU-level categories using transfer learning with EfficientNet-B0. The model is deployed as an interactive Streamlit app enabling real-time product predictions from uploaded images.

🧠 Model Architecture

Base Model

EfficientNet-B0 (pre-trained on ImageNet)

Training Strategy

Transfer Learning with Fine-tuning

Optimization

Mixed-Precision Training (AMP) with AdamW

Hardware

NVIDIA RTX 2050 GPU (Windows)

Training Configuration

Dataset: RPC (Retail Product Checkout) - ~200+ categories
Image Size: 224×224 pixels
Batch Size: 32
Epochs: 15-20
Learning Rate: 0.001 (with cosine annealing)

    prediction = model.predict(image)

    st.write(f"Confidence: {prediction['prob']:.2%}")
